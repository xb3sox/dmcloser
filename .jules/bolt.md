## 2025-05-22 - Single-Pass Text Normalization & Array Reversal in Shared Domain
**Learning:** In multi-predicate guard checks (such as `detectRisk` evaluating spam, injection, refund, secret, clinical, and opt-out patterns), sequentially calling helper functions that each re-normalize text executes redundant regular expression replacements and string allocations (up to 6x overhead per evaluation). Similarly, helper functions like `matchedTest` in lead scoring that re-copy and reverse array slices (`[...incoming].reverse()`) on every evaluation create unnecessary allocations per score calculation.
**Action:** Normalize input text once at the top-level classification entry point and pass the normalized string to pattern testers. Pre-reverse array slices once before multi-predicate iterations across message histories.
